# blink LED example code for the Raspberry Pi Pico
This is a simple example of how to blink an LED using the Raspberry Pi Pico. The code is written in C and uses the Pico SDK.

Documentation for the Pico SDK can be found here: https://pip-assets.raspberrypi.com/categories/610-raspberry-pi-pico/documents/RP-008276-DS-1-getting-started-with-pico.pdf
